# Prague Parking V1

Mitt program för inlämningsuppgiften Prague Parking.

Programmet har 100 parkeringsplatser. På varje plats kan det stå
en bil eller upp till två motorcyklar.

I menyn kan man:
- Visa parkeringen
- Parkera ett fordon
- Söka efter ett fordon
- Flytta ett fordon
- Hämta ut ett fordon
- Avsluta programmet

Fordon identifieras med registreringsnummer och platserna visas
som 1–100. Inget sparas när programmet stängs.

## Starta programmet

Projektet använder .NET 10. Du behöver .NET 10 SDK och en
Visual Studio-version som stöder det.

Öppna Prague ParkingV1.slnx i Visual Studio och kör med
F5 eller Ctrl+F5.

Skriv siffran för ditt menyval och tryck Enter.
